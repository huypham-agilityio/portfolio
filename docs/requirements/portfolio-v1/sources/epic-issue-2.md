## Comment by @huypham-agilityio

Decisions on the open questions, as PO. These are final for v1.

**1. Browsers and screen sizes**
- Support the last 2 versions of Chrome, Safari and Firefox, plus iOS Safari and Android Chrome.
- Minimum width is 320px. Check at 320 / 375 / 768 / 1280+ px, portrait and landscape. No horizontal scroll, no clipped text.

**2. Dark mode (T2)**
- On first visit the page follows the system preference.
- The manual toggle overrides it and the choice persists across reloads.
- If storage is blocked, the page still renders correctly using the system preference.
- No visible flash of the wrong theme on load.
- Contrast must be acceptable in both themes.

**3. Placeholder check (T7)**
- A manual checklist is enough for v1. Blocking the production deploy automatically is phase 2.
- Use one agreed, searchable marker on every placeholder (for example `[PLACEHOLDER]`), including image alt text, page title, meta description and link targets.
- Launch sign-off requires a search for the marker across content and assets that finds nothing.

**4. v1 scope**
- In v1: page title and meta description, basic accessibility (keyboard navigation, contrast, alt text, accessible names on links), and a basic 404 page.
- Phase 2: Open Graph social preview, and any formal performance budget.

**Contact (T6) details from the QA review**
- Show the email address as visible text as well as a `mailto:` link, so it works with no mail client.
- GitHub and LinkedIn open in a new tab with `rel="noopener noreferrer"`.
